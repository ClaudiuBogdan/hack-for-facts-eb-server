# Review — budget legacy roots on the kernel (`dev` @ 85ecf30e, 2026-09-09)

Scope: `src/modules/budget/{core/legacy-analytics,core/legacy-dimensions,shell/graphql/legacy,shell/repo/legacy-*,shell/repo/grouped-*,shell/repo/map-*,shell/factors,shell/mcp}`, the commitments commits cf091685 / 08a7fb6b, and the legacy modules they replace. Read-only review; no DB queries; no files changed except this one.

## Summary

1. No rule violations found in the slice: no `throw` in `core/`, no float arithmetic on money (Decimal end to end, `Number`/`parseInt` only on years, ids and counts), no `JSON.parse`, no writes, no cross-module internals; the byte-identity SDL test exists and is sound for the 40 carried execution-analytics + dimension definitions.
2. The biggest structural gap is documentary/contractual, not a code bug: doc 13 §2/§4 say `heatmapCountyData`, `heatmapUATData`, `commitmentsSummary`, `commitmentsAggregated`, `commitmentsAnalytics` are served by the budget legacy slice, but no kernel implementation exists and the client still sends them to legacy `/graphql` — this blocks §5 step 7 (retire legacy), not current serving.
3. The standalone kernel (`redesign-api.ts` → `buildRedesignApp`, the end-state composition root per doc 13 §5 step 7) enables `ins-native` by default and swaps `executionAnalytics` to the strict native series (factor set 2, dropped points, `missingPeriods`), contradicting the accepted decision (legacy policy + set 1 pin) and doc 13 §7/§9; the shipped `api.ts` bridge does not pass `ins-native`, so production runs the legacy policy only until retirement. Nothing in `docs/` records the switch.
4. Two contract deltas exist in code but not in the doc 13 table: a null/zero per-capita population now aborts with `ServiceUnavailable` (legacy served unadjusted), and two additive fields (`AnalyticsFilterInput.is_territorial_executive`, `AnalyticsSeries.missingPeriods`) were added to frozen types with only a test-side carve-out.
5. Commitments: cf091685 is correct (group by entity/period then sum; e2e covered); 08a7fb6b restores all 8 `*_disponibile` columns on the fact path and the annual MV already carried them. What the kernel still omits vs the legacy commitments module: the 10 non-common MV metrics for timeseries/ranking, and the derived `total_plati` / `execution_rate` / `commitment_rate` summary fields.
